## Overview

Convertly provides a simple way to change image formats from a web browser instead of using a desktop application. It is intended for quick JPG, PNG, WEBP, and HEIC conversion while keeping the complete process on the client device.

Since the browser performs the work locally, images do not need to be uploaded to an external service. The interface is designed for use on desktop computers as well as mobile devices, making it suitable for routine image conversion wherever you are working.

## Frequently Asked Questions

**Are images sent to a server?**  
No. Convertly is built to process selected images locally in the browser without uploading them.

**Will it work on mobile devices?**  
Yes. The project is intended for both desktop and mobile use, including phones and tablets.

**Which image formats can it handle?**  
Convertly includes JPG, PNG, WEBP, and HEIC support, with the available conversion paths focused on these formats.

**How can I find the newest version?**  
Open the latest hosted build, or review the repository for release information and project updates.

**Why might a conversion fail?**  
Check that the selected format is supported, your browser is current, and the image is not damaged. For a locally hosted copy, also verify that the project files are being served properly.
